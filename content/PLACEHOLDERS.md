# المحتوى الذي يجب استبداله قبل الإطلاق

الموقع يعمل الآن على محتوى تجريبي. كل قيمة تخصّ هوية صاحب الموقع أو
بياناته الرسمية موسومة في الكود بـ `[PLACEHOLDER]`، وفحص
`npm run check:placeholders` يفشل إذا بقي أي وسم عند استهداف دومين فعلي.

محتوى الدورات والمقالات مكتوب كنص واقعي **بلا وسم** عمداً: الغرض منه اختبار
التخطيط على أطوال نص حقيقية بالعربية والإنجليزية معاً — والعربية أطول
بـ ١٥–٢٥٪ من الإنجليزية للمعنى نفسه. استبدله بمحتواك الفعلي، لكن غيابه
لا يمنع النشر تقنياً.

مكان المحتوى التجريبي كله: `src/lib/content/placeholder.ts`.
بعد ربط Sanity يصبح ملفاً احتياطياً فقط ولا يظهر للزوار.

## ١. الهوية والبيانات الرسمية (إلزامي)

| العنصر | أين | ملاحظات |
|---|---|---|
| الاسم الكامل | `placeholderSiteSettings` → `fullName` | بالعربية والإنجليزية |
| المسمّى المهني | `headline` | يظهر في Hero وفي بيانات Person المنظمة |
| النبذة القصيرة والمفصّلة | `shortBio` و `longBio` | القصيرة تُستخدم كوصف SEO |
| الصورة الشخصية | `avatar` | صورة احترافية + نص بديل |
| السيرة الذاتية PDF | `cvAr` / `cvEn` | نسختان، تظهران كزر تحميل في صفحة «عني» |
| البريد الإلكتروني | `email` | يظهر في صفحة التواصل وسياسة الخصوصية |
| رقم الواتساب | `whatsappNumber` | بصيغة E.164 — يُستخدم في رابط wa.me وفي Cloud API |
| روابط التواصل | `socials` | LinkedIn و GitHub و YouTube |
| الإحصائيات | `stats` | عدد المتدربين والدورات والدول وسنوات الخبرة |
| المسار المهني | `timeline` | أسماء الشركات والجامعات الحقيقية |

## ٢. الشهادات (إلزامي)

كل شهادة تحتاج: صورة فعلية، نص بديل وصفي، الجهة المانحة، تاريخ الإصدار،
رقم الاعتماد، ورابط تحقق رسمي. الروابط التجريبية كلها `example.com`.

## ٣. آراء المتدربين (إلزامي — وله بُعد قانوني)

اللقطات الحالية مولَّدة برمجياً في `public/placeholder/`. لكل رأي حقيقي:

1. **تأكيد موافقة صاحبه على النشر** — `consentGiven` مطلوب في مخطط Sanity،
   والرأي بلا موافقة لا يُعرض.
2. **طمس البيانات الحساسة** داخل اللقطة: أرقام الهواتف، صور الملفات
   الشخصية، أي معلومة تعريفية لم يوافق صاحبها على نشرها.
3. **نص بديل يصف فحوى الرأي** — إلزامي، وبدونه تُسقَط الوثيقة.
4. **نص مفرّغ** — اختياري تقنياً، لكنه شرط ظهور الرأي في البيانات المنظمة
   وفي نتائج البحث.

## ٤. الدورات والخبرة الأكاديمية

العناوين والمناهج والأسعار والدفعات الحالية أمثلة معقولة لا بيانات حقيقية.
انتبه خاصة إلى:

- **الأسعار**: القرار لكل دورة — سعر معلن أم «اطلب عرض سعر» (حقل
  `corporate.showPrice`).
- **المقاعد المتبقية**: تُحدَّث يدوياً من الاستوديو. الموقع يمنع التسجيل
  تلقائياً عند وصولها إلى صفر.
- **المناطق الزمنية**: بصيغة IANA لكل دفعة، لأن الأوقات تُعرض بتوقيت
  الدورة وبتوقيت الزائر معاً.
- **أسماء الجامعات** في `placeholderTeaching`.

## ٥. إعدادات خارج المحتوى

| العنصر | أين |
|---|---|
| الدومين | `NEXT_PUBLIC_SITE_URL` — بدونه تكون روابط canonical و OG خاطئة |
| مشروع Sanity | `NEXT_PUBLIC_SANITY_PROJECT_ID` وتوكن الكتابة |
| البريد | `RESEND_API_KEY` و `NOTIFICATION_EMAIL_TO` |
| الواتساب | حساب Meta Business موثّق + **قالبان معتمدان** بالعربية والإنجليزية |
| سياسة الخصوصية | `src/app/[locale]/privacy/page.tsx` — صياغة أولية تحتاج مراجعة قانونية |

## ٦. مسارات تعتمد على أطراف خارجية — ابدأها مبكراً

1. **اعتماد قوالب واتساب من Meta**: أيام محتملة، وقابل للرفض وإعادة الصياغة.
   حتى اعتمادها يعمل الموقع بمسار wa.me البديل تلقائياً.
2. **جمع لقطات الآراء وموافقات أصحابها**: يعتمد على أشخاص آخرين.
3. **توثيق حساب Meta Business**: يسبق كل ما يتعلق بالواتساب.
