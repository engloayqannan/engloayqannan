# موقع مدرّب Front-End — ثنائي اللغة

موقع شخصي لمدرّب Front-End دولي: عربي RTL وإنجليزي LTR، كتالوج دورات مع
دفعات ومقاعد، تسجيل مباشر بتأكيد بريدي وواتساب، شهادات وآراء متدربين
وخبرة أكاديمية ومدونة.

المواصفات الكاملة في [`SPEC.md`](./SPEC.md) — هذا الملف للتشغيل فقط.

## التشغيل

```bash
npm install
npm run dev        # http://localhost:3000 → يعيد التوجيه إلى /ar أو /en
```

**الموقع يعمل بالكامل بلا أي متغيّر بيئة.** بلا Sanity يقرأ محتوى تجريبياً
واقعياً، وبلا Resend أو Meta يتخطّى الإشعارات ويسجّل تحذيراً. انسخ
`.env.example` إلى `.env.local` وأضف ما تحتاجه فقط.

## الأوامر

| الأمر | ما يفعله |
|---|---|
| `npm run dev` | خادم التطوير |
| `npm run build` | بناء الإنتاج |
| `npm run lint` | ESLint |
| `npm run typecheck` | فحص الأنواع |
| `npm test` | اختبارات الوحدة (Vitest) |
| `npm run test:e2e` | اختبارات E2E وإمكانية الوصول (Playwright) |
| `npm run check:placeholders` | بوابة الإطلاق: لا محتوى تجريبي على دومين فعلي |

اختبارات E2E تحتاج بناءً حديثاً (`npm run build`) لأنها تشغّل `next start`.
في بيئة يوجد فيها Chromium مثبّت مسبقاً بإصدار مختلف:

```bash
PLAYWRIGHT_CHROMIUM_PATH=/path/to/chrome npm run test:e2e
```

## البنية

```
src/app/[locale]/     صفحات الموقع باللغتين
src/app/api/          التسجيل، التواصل، إبطال الكاش
src/lib/content/      طبقة القراءة الوحيدة: Sanity أو المحتوى التجريبي
src/lib/courses/      منطق حالة الدفعات والمقاعد
src/lib/notifications/ البريد والواتساب وإعادة المحاولة
sanity/schemas/       مخططات المحتوى (تُستهلك بعد تثبيت حزمة sanity)
e2e/                  المسارات الحرجة و a11y
```

## قرارات يجب معرفتها قبل التعديل

**المقاعد لا تُخزَّن في الكاش.** كل الصفحات ثابتة عدا لوحة الدفعات وصفحة
التسجيل. عرض «متبقٍ ٣ مقاعد» وهي ممتلئة خطأ منتَج لا خطأ أداء.

**فشل الإشعار لا يُفشل التسجيل.** إذا حُفظ الطلب ثم فشل الواتساب، الاستجابة
ناجحة والفشل مسجَّل. الحالة الوحيدة التي تُرجِع خطأً هي ألّا يصل الطلب إلى
مخزن ولا إلى بريد المدرّب.

**التوقيت السريع إشارة لا رفض.** حقل الشرك وحده يبرّر رفض الطلب؛ الإرسال
السريع يُعلَّم فقط، لأن مستخدم التعبئة التلقائية قد يرسل في ثانيتين
وفقدان تسجيل حقيقي أسوأ من مرور سبام.

**لا صورة بلا نص بديل.** الآراء والشهادات بلا نص بديل تُسقَط من العرض بدل
أن تُنشر غير مقروءة — وهذه قاعدة مفروضة في طبقة البيانات لا في المكوّن.

**الخصائص المنطقية إلزامية.** استخدم `ms-*`/`me-*`/`ps-*`/`pe-*`/`start`/`end`
ولا تستخدم `left`/`right`. اختبار E2E يفشل عند ظهور تمرير أفقي في صفحة
عربية.
